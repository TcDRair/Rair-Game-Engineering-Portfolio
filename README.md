# Rair · 게임 개발 포트폴리오

C#과 Unity로 게임 시스템과 개발 도구를 만들었습니다. 여러 프로젝트의 작업 중 구현 과정과 기술적 선택을 되돌아볼 수 있는 사례를 골랐습니다.

[포트폴리오 PDF](TcDRair_Game_Engineering_Portfolio.pdf)

![BuilderRPG에서 생성한 섬](https://raw.githubusercontent.com/TcDRair/BuilderRPG/ff4592bf830bcffe0cffec7a73430ea75390d08b/docs/images/island-01-overview.png)

BuilderRPG의 절차적 지형. 시드 `20260730`, 512×512, 목표 육지 비율 45%, 강 14개.

| 사례 | 주요 내용 |
|---|---|
| [BuilderRPG · 2D 지도에서 3D 지형으로](docs/builder-rpg.md) | 공간 탐색 개선, Terrain·프롭 적용, 에디터와 런타임의 실행 경로 분리 |
| [여러 프로젝트의 개발 도구](docs/editor-tools.md) | UI 색상 관리, 어셈블리 참조 설정, 상호작용 편집과 반복 실행 |
| [LiC2 · 에이전트 역할 조율과 스프린트 운영](docs/lic2.md) | 하네스 도입, 스프린트 계약과 역할별 전달물, 평가·재검증 |

BuilderRPG의 [원본 코드](https://github.com/TcDRair/BuilderRPG)와 [상세 기술 문서](https://github.com/TcDRair/BuilderRPG/tree/master/docs)는 공개되어 있습니다. Traveler’s Choice·CTS·LiC·LiC2의 원본 저장소는 현재 비공개입니다.
